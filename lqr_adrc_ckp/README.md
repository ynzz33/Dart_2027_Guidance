# 无动力 X 构型飞镖 · LQR前馈 + LADRC + X分配 仿真

> 一套纯 MATLAB 的姿态控制仿真：为「无动力、四舵机、X 构型」飞镖实现
> **外环 LQR（标称跟踪 + 微分前馈）→ 内环 LADRC（自抗扰）→ X 构型加权伪逆控制分配 → 二阶舵机 → 6DOF 非线性动力学**
> 的完整闭环，1000 Hz 定步长，含陀螺噪声、Dryden 紊流 + 常值侧风。

本文件 = **项目说明 + 参数整定指南**。怎么把环境跑起来、每个命令怎么敲、看哪张图，请看配套的 **[`DEPLOY_GUIDE.md`](DEPLOY_GUIDE.md)**。

## 1. 它要解决什么问题

飞镖出管后**没有动力**，靠惯性飞、靠阻力减速、靠重力下坠，工况很“拧巴”：

| 难点 | 物理根源 | 本方案怎么应对 |
|---|---|---|
| 速度大幅衰减 60→20 m/s | 动压 q̄=½ρV² 变 1/9，舵面效率随之变 1/9 | **控制分配用实时动压调度**，低速自动加大舵偏补偿 |
| 偏航效率极低 | 方向舵效 Cndr≈-0.1（比俯仰小一个量级） | **分配中给偏航极低权重**，放弃主动控偏航，靠气动 Cnβ/Cnr 被动增稳 |
| 滚转-俯仰-偏航强耦合、风扰、模型不确定 | 旋转耦合 ω×Iω、攻角/侧滑扰动力矩 | **内环 LADRC** 把这些统统当“总扰动”估出来对消 |
| 姿态跟踪要快又稳 | — | **外环 LQR** 给出最优角速度指令 + 参考微分前馈 |

### 目标指标与达成情况

| 指标 | 要求 | 实测（见各测试） | 结论 |
|---|---|---|---|
| 滚转阶跃超调 | <20% | **0.7%** @50m/s | ✅ |
| 俯仰阶跃超调 | <20% | **0.4%** @50m/s | ✅ |
| 调节时间 ts | <0.5s @50m/s | 滚转 **0.389s** / 俯仰 **0.392s** | ✅ |
| 稳态误差 | 无静差 | 滚转 **-0.006°** / 俯仰 **-0.001°** | ✅ |
| 偏航 | 仅增稳 | 阶跃工况 max\|ψ\|=**0.018°** | ✅ |
| 速度衰减性能降级 | <30% | 不饱和区(V≥40) **0.3%** | ✅ |
| 抗常值风扰 | 滚转/俯仰无静差 | phi_err **0.062°**、theta **0.074°** | ✅ |

> 说明：低速（V≤30）+ 大角度阶跃会触 ±25°/±200°/s 舵面上限，那是**幅度上限**而非性能降级；
> 偏航对常值侧风是**设计上的弱轴**（Cndr 故意取小），只增稳不强求消除。详见第 5 节与 `t4_robustness`。

## 4. 参数整定指南（核心）

> 所有可调参数都集中在 `dart_params.m`。下面讲**每个关键参数怎么调、为什么是现在这个值**。

### 4.1 外环 LQR 增益 K —— 决定姿态跟踪快慢

对象是纯积分器 `[φ̇;θ̇;ψ̇]=[p;q;r]`（A=0, B=I），LQR 有**解析解**：

```
K = diag( sqrt(diag(Q)./diag(R)) )
```

- 当前 `Q=diag([36 36 3.6])`、`R=diag([1 1 0.1])` ⇒ **K=diag([6 6 6])**。
- 单看外环：每通道闭环 ẋ=−K·x，时间常数 τ=1/K=0.167s。
- **想更快**：同比例放大 Q（保持 10:10:1 相对权重）→ K 变大。但 K 不能无限大，受下一条约束。

### 4.2 外环 K 与内环 wc 的“联合”关系 —— 这是整定的关键

外环给角速度指令、内环（带宽 wc）去实现，两级串起来近似一个**二阶系统**：

```
闭环自然频率   ωn ≈ √(wc · K)
闭环阻尼比     ζ  ≈ 0.5 · √(wc / K)
```

- 当前 `wc=16, K=6` ⇒ ωn≈√96≈**9.8 rad/s**，ζ≈0.5·√(16/6)≈**0.82**。
- ζ≈0.82 落在“快且几乎不超调”的甜区 ⇒ 实测超调<1%、ts≈0.39s。✅
- **关键直觉**：要稳，就得让 **wc 比 K 大**（内环比外环快）。若 wc 和 K 都往大调但比例失衡，ζ 会偏离 0.7~1，要么超调、要么迟钝。
- 用 `tests/probe_gain.m` 扫 wc×K 网格，可直接看到超调/调节时间随两者怎么变——**改完 Q 或 wc，先跑它确认 ζ 还在甜区**。

> 反例（提纲起点 wc=30, K≈3.16）：ωn≈9.7 但 ζ≈1.5 过阻尼 ⇒ ts≈2.7s 太慢（见 t3 打印的 “outline start”）。

### 4.3 内环 LADRC：观测器带宽 w0、控制带宽 wc、增益 b0

| 参数 | 当前值 | 作用 | 调法 |
|---|---|---|---|
| `wc` | 16 | 控制带宽，定内环响应快慢 | 见 4.2，与 K 联调 |
| `w0` | 100 | 观测器带宽（≈6×wc） | 越大估扰动越快，但越放大陀螺噪声；一般取 (3~10)×wc |
| `b0` | [1/Ixx,1/Iyy,1/Izz] | 力矩→角加速度增益 | = 1/转动惯量，物理量，不用瞎调 |

- **w0 经验**：先取 5×wc，若抗扰慢就加大、若舵抖（噪声放大）就减小。本项目 100≈6.25×16 兼顾两者。
- LADRC 几乎不依赖精确模型，所以气动系数即使估不准，靠 LESO 估总扰动也能稳——这正是选它的理由。

### 4.4 控制分配权重 W —— 偏航弱轴的处理

```matlab
params.alloc.W = diag([1 1 0.1]);   % [滚转 俯仰 偏航]
```

- 偏航权重要轻但不必极端。偏航舵效 Cndr≈-0.1 极小，要产生像样的偏航力矩需要数倍于俯仰的舵偏；
  X 构型里偏航靠 4 舵差动，若 W(3,3) 过大（如 ≥0.3）会在强侧风下让偏航跟滚转抢舵权 → 滚转跟踪超调。
- **0.1 是折中**：比旧 ±25° 舵机时的 0.05 给更多偏航主动控制权（±90° 舵权充裕），
  但在强侧风下仍偏顺气动 **Cnβ/Cnr 风向标被动增稳**，不与滚转/俯仰争抢。
- **实测**：W(3,3)=0.3 时 4 m/s 侧风滚转超调 +12°；降到 0.1 后恢复准确跟踪（0.029° 误差）。
- `eps=1e-6` 是正则项，防 BᵀW²B 接近奇异时数值爆，一般不用动。

### 4.5 舵机与饱和

- `wn=2π·15`（~15Hz 带宽）、`zeta=0.7`、`±90°`、`±200°/s`：180° 总行程舵机。
- **饱和几乎不是问题**：±90° 下即使强风大机动也远不到限位。
- 若换成小行程舵机（如 ±25°），需参考旧版 README（见 git log）——那时饱和是核心调参约束。

### 4.6 演示场景的风强度

`main_dart_sim.m` 里的演示风用 **σ=1.0 + 侧风 2.5 m/s**（中等偏强），
±90° 舵机轻松扛住，峰值舵偏 ~49°（远在 90° 以内），滚转跟踪误差 <0.03°。

- 想做**极限抗扰**演示 → 用 σ=1.5 + 侧风 4 m/s（`params.wind` 默认值），舵偏会更大但仍在 90° 内。
- 想做**更干净飞行** → 降回 σ≈0.3、侧风≈1.0。

## 5. 关键设计抉择（为什么这么建模）

### 5.1 两套仿真：姿态台 `att_bench` vs 6DOF 自由飞 `main`

- **姿态台**（M3/M4 用）：把速度“焊死”在 [V;0;0]，攻角/侧滑恒 0、动压恒定，只演化转动+姿态。
  好处：干净、可重复，能精确量超调/调节时间——**所以姿态环指标都在这里考**。
- **6DOF 自由飞**（main 用）：12 状态全演化，速度/弹道由力自然决定。**真实但“脏”**，用来做端到端演示。

### 5.2 无动力弹体“怎么飞才对”：俯仰必须跟踪弹道倾角 γ

飞镖会往下掉。若硬让机头保持固定俯仰角，而速度方向在往下偏 → **攻角 α 越来越大 → 静稳定力矩 Cmα·α（Cmα=-8 很强）暴增 → 舵面拼命对抗直到饱和发散**。
正确飞法是**俯仰跟踪 γ**（顺着气流飞，α≈0、最省舵）；把主动机动放在不影响弹道的**滚转**通道演示。
→ main 实测：α RMS 1.59°，滚转 10° 机动跟踪误差 −0.029°，偏航 2.1°，峰值舵偏 48.7°（远在 90° 以内）。

### 5.3 偏航是”效率偏低的通道”，但 ±90° 舵机下舵权充裕

偏航舵效 Cndr≈-0.1 仍小，但 ±90° 舵机让偏航有足够舵权去主动控制。
W(3,3)=0.1 是折中值——既不完全依赖气动被动增稳，也不让偏航在强侧风下挤占滚转/俯仰。
`t4_robustness` 如实呈现：滚转/俯仰对风扰无静差，偏航偏离在 0.04° 量级。
