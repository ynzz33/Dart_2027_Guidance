# 主脚本 Guidance_vision_scrpit.py 识别逻辑说明

> 本文档描述 OpenMV 端主脚本 [Guidance_vision_scrpit.py](Guidance_vision_scrpit.py) 的识别管线（绿灯追踪 + 给飞控发坐标）。
> PC 端离线回放视频用的工具见 [视频测试使用方法.md](视频测试使用方法.md)。
>
> ⚠️ **高频调参期**：文中所有阈值 / 档位数值均为**某时刻快照**，一律**以代码为准**（主脚本顶部「常用可调参数区」+ `DIST_TIERS`）。

## 1. 硬件与图像设置

- OpenMV H7，RGB565，QVGA 320×240
- `set_transpose(True)` → 图像变成 **240 宽 × 320 高**（整体逆时针转 90°）
- `set_vflip(True)`：垂直翻转（镜头倒装补偿）
- 曝光 / 增益 / 白平衡**全部锁定**（`LOCKED_EXPOSURE_US=2000`、`LOCKED_GAIN_DB=10`、RGB 增益固定）——颜色识别的前提是画面亮度稳定

## 2. 坐标系（发给飞控的坐标）

- 画面中心 **(120, 160)**（= 240/2, 320/2）
- x 右为正、y 上为正（图像 y 向下，计算时翻 Y）
- 固定偏移：`FRAME_X_OFFSET = -5`、`FRAME_Y_OFFSET = 145`（俯仰偏置，装夹后标定）
- 输出公式（LPF 前）：`raw_x = cx - 120 - (-5)`，`raw_y = 160 - cy + 145`
- 一阶低通 `LPF_FACTOR = 0.3` 平滑后发出 `(x_out, y_out)`
- 飞控收到后自行换算成度：`YAW = y/160*72`、`PITCH = x/120*54`

## 3. 三档距离自适应（DIST_TIERS）

| 档 | 像素范围 | 大概距离 | 特点 |
|---|---|---|---|
| **FAR** | 3 ~ 15 px | > 5 m | 启动 / 丢目标的默认档。LED 小且颜色淡，L 上限放 100 兜底洗白中心，A_max 收紧滤草坪/绿广告牌 |
| **MID** | 18 ~ 3000 px | 1 ~ 5 m | 工作区间，参数最标准，调参先调这一档 |
| **NEAR** | 3000 ~ 15000 px | < 1 m | 中心必然过曝白化，靠"白核 + 绿环"（HALO）形态兜底 |

每档一套参数：LAB 阈值 `threshold`（L_min, L_max, A_min, A_max, B_min, B_max）、亮度范围、`pixels_threshold`（find_blobs 最小连通像素）、圆度、密度、中心绿点数、中心饱和点数、环绿点数、环噪容忍（具体值以代码为准）。

**切档规则**：只看**锁定目标**的像素数（`pick_tier`）；启动 / 丢目标停在 FAR；丢 5 帧强制回 FAR。像素 15~18 之间没有档（衔接缝隙，落回 FAR）。

## 4. 每帧识别流水线

1. **选档**：`pick_tier(track_pixels)` —— 上一帧锁定目标的像素数决定本帧用哪档
2. **ROI 预测**：`predict_roi` —— 按"上帧位置 + 速度外推 + 丢失帧数"算搜索窗；连续丢 10 帧放弃 ROI 回全图搜
3. **找候选**：`find_blobs(档位 LAB 阈值, merge=True, pixels_threshold)` —— LAB 粗筛出绿色连通块
4. **逐个校验**：`measure_green_blob`，按计算代价从低到高：
   - 圆度 → 密度 → 亮度均值（L）→ 色度 a（越负越绿）
   - **结构化采样**：中心 5 点 + 外环 4 点（沿 blob 主轴方向，LED 倾斜成椭圆时采样不落空）
   - **模式分类**：`SOLID`（中心见绿，远/中距标准）或 `HALO`（白核 + 环绿，近距过曝标准），都不满足则拒（S）
   - 两个快路径：跟踪命中位置附近跳过采样（省 1-2ms/帧）；FAR 档 <14px 微小 blob 信任阈值直接过
5. **打分选优**：面积 + 圆度 + 中心绿 + 环绿 − 环噪（HALO 加分），再加跟踪距离奖惩（±30 / −80）防多绿灯时跳目标
6. **时序跟踪**：`update_tracking` —— 连续命中 2 帧才锁定上报；丢失容忍 4 帧（ROI 继续外推）；≥10 帧彻底清零回全图搜
7. **输出**：`compute_target_xy` —— 中心化 + 翻 Y + 偏移 + LPF → `(x_out, y_out)`

## 5. 距离估算

- `dist_cm = DIST_K / sqrt(像素数)`，`DIST_K = 1000`（现场标定：`K = 距离cm × sqrt(N)`，50cm 处量像素数 N）
- 反平方根粗估，只供参考，不做控制闭环

## 6. UART 协议（与飞控通信）

**上行（OpenMV → 飞控）**：

| 包 | 格式 | 含义 |
|---|---|---|
| 识别 | `0x5A + x(2B) + y(2B) + 0xA5` | 识别到目标，发坐标（uint16 大端） |
| 丢目标 | `0x7A + 0 + 0 + 0xA7` | 没识别到，心跳"无目标" |
| 距离面积 | `0x5B + dist(2B) + area(2B) + 0xA6` | 距离 cm + 目标像素数，识别成功后追加发 |
| 录像状态 | `0x9A + (1,0)/(1,5) + 0xA9` | 录像开始 / 结束通知 |

**下行（飞控 → OpenMV）**：`0x5A + cmd + 0xA5`
`0x00` 识别开 / `0x01` 识别停 / `0x02` 自检 / `0x03` 录像开 / `0x04` 录像停

**调试帧（飞控 → OpenMV，仅 HUD 显示用）**：`0x57 + 12×float(大端) + 0x75` —— ACC/陀螺/当前欧拉角/目标欧拉角共 12 个量

## 7. 录像与日志

- SD 卡挂载后按命令录像：`record_*.mjpeg`（视频，每 N 帧抽 1 帧）+ `log_*.txt`（文本日志，每帧一行：档位/像素/距离/坐标/fps/pattern + IMU 12 量）
- `DEBUG_AUTO_RECORD=True` 时 SD 挂载即自动开录（调试用；**比赛必须改 False**，等飞控 0x03 命令）
- 录完必须走完"停录"流程（飞控会发 0x04 并等反馈），否则 SD 上文件可能 0KB

## 8. 主机端还原注意（用 video_test.py 时）

- OpenMV LAB 与 OpenCV LAB 的**换算公式不同**（OpenMV 近似快算、OpenCV CIE 标准），阈值附近的 blob 在 PC 端可能与实机有小差异
- 主机端只能"还原个大概、看哪些帧出问题"，**不能当 bit-exact**，识别结果以实机为准
