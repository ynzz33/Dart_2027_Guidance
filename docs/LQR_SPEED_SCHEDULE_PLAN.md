# LQR 速度调度与 LQI 演进计划

> 状态：计划阶段，未编译、未上台架、未飞行验证。
>
> 适用范围：Dart_2027 飞镖 X 翼姿态 LQR、速度调度、积分补偿和末端结束判据。

## 1. 已确认的问题与边界

当前实测结论是：

- 使用固定设计速度 `V=6 m/s` 计算的 `K6`，全程保持不变时效果较好；
- 将实时速度代入 `K(V)` 后，控制效果变差，尾端尤其明显；
- 角速度状态一直实时反馈；
- 角速度对应的 K 增益随速度变化，本来就是速度调度的设计目标，不冻结角速度列；
- 不使用积分时存在静态误差；
- 飞行过程中速度总体增加，撞击后速度下降。

因此本计划不采用以下做法：

1. 不在姿态误差或角速度反馈环内增加低通滤波；
2. 不单独冻结角速度反馈 K；
3. 不同时修改速度调度、积分、Q/R、模型和状态机；
4. 不把速度下降作为唯一的撞击/结束判据。

## 2. 控制目标

在保留已经验证过的固定 `K6` 基线的前提下，逐步确认并解决实时 `K(V)` 变差的原因：

```text
固定 K6 可用
    ↓
确认实时 K(V) 变化本身的问题
    ↓
确认速度代理与真实气动舵效的关系
    ↓
确认 MATLAB B(V) 模型与真实 B(V) 的差异
    ↓
在有边界保护的情况下恢复速度调度
    ↓
最后叠加积分，必要时设计真正的增益调度 LQI
```

最终不以“多项式拟合误差小”作为成功标准，而以真实闭环表现为准：

- 姿态误差不发散；
- 角速度阻尼不因错误调度而变弱或变号；
- 舵面不出现新的持续饱和；
- 不因速度估计波动提前进入 `End`；
- 调度后的静态误差不劣于固定 `K6`；
- 调度 K 变化不会造成明显控制输出跳变。

## 3. 阶段一：固定 K 建立基线

### 3.1 固定条件

固定以下条件，不修改控制结构：

```text
K = K6
速度调度关闭
Q/R 不变
舵面限幅不变
姿态和角速度反馈不变
状态机不变
```

### 3.2 两组基线试验

#### A. 固定 K6、关闭积分

目的：确认纯 LQR 的动态稳定性，观察：

- 尾端姿态误差；
- 尾端角速度是否逐渐增大；
- 四个舵面的原始输出和限幅后输出；
- 是否出现持续舵面饱和；
- 是否提前进入 `End`。

#### B. 固定 K6、打开积分

目的：消除静态误差，建立固定 K6 下的积分基线，记录：

- 积分补偿量；
- 积分是否造成低频摆动；
- 舵面饱和时积分是否继续累积；
- 目标更新或状态切换时积分是否产生突变。

## 4. 阶段二：隔离实时速度调度

第一轮对比必须关闭积分，只比较 K 的变化：

```text
A：固定 K6
B：实时 K(V)
```

两组必须保持相同：

- Q/R；
- 目标输入；
- 舵面限幅；
- 控制周期；
- 状态机条件；
- 姿态和角速度反馈；
- 舵机输出映射。

实时调度测试中必须确认调用生成函数时实际传入的是实测速度，而不是设计速度常数，并确认 Vofa 看到的 `V_used` 与 K 计算使用的是同一个值。

### 4.1 必须记录的量

优先复用现有 `lqr_ctrl` 结构，不新增大量长期全局变量。需要记录：

```text
V_raw              原始速度
V_used             实际用于生成 K 的速度
K(V)               当前 K 矩阵
x[0..5]            姿态误差和角速度
u_raw[4]           限幅前舵面输出
u[4]               限幅后舵面输出
Guidance_State     状态机状态
integral.err[3]    积分状态
```

另外把 LQR 输出分解观测为：

```text
u_angle = -K_angle(V) × angle_error
u_gyro  = -K_gyro(V) × angular_rate
```

重点判断尾端失控前：

- K 是否跳变；
- `u_gyro` 是否相对固定 K6 明显变小；
- 角速度是否先增大；
- 舵面是否已经饱和；
- 状态机是否提前变为 `End`。

## 5. 阶段三：速度调度器的安全边界

### 5.1 不使用反馈低通

不对姿态、角速度、舵面输出加低通。

速度调度器只增加以下保护：

- 速度有效性判断；
- 速度分档滞回；
- 速度异常时保持上一组 K；
- 速度失效时退回 `K6`；
- K 从旧值到新值的无扰过渡。

K 的无扰过渡属于调度参数保护，不是姿态反馈低通。它的目的只是避免速度估计一次跳变导致整块 K 同步跳变。

### 5.2 速度限幅的正确作用

将速度限制在 MATLAB 的拟合范围内，可以解决区间外多项式外推问题；但不能解决：

```text
真实速度与估计速度不一致
真实空速与世界速度不一致
真实 B(V) 与 MATLAB 模型不一致
```

因此速度限幅保留，但不能把它当作速度可信度保护的全部。

### 5.3 先保留完整 K(V) 调度

角度列和角速度列都按 `K(V)` 更新，不人为冻结某一类列。

如果数据证明某一类反馈贡献在尾端明显错误，再针对模型或该类增益处理；在没有数据前不改变 LQR 的完整状态反馈结构。

## 6. 阶段四：建立用于调度的速度

当前 EKF 输出的世界系速度模长可以作为速度代理，但它不等于气动空速。

项目中机体前向为 Y 轴，现有机体系速度位于：

```text
IMU_Data.Velocity[Body][NOW][Y]
```

### 6.1 临时速度代理

第一版可考察机体系前向速度：

```text
V_forward = abs(IMU_Data.Velocity[Body][NOW][Y])
```

它比世界系三轴速度模长更接近飞镖纵轴方向的主要气动速度，但仍然属于地速/估计速度代理，不是真空速。

### 6.2 速度可信度门控

只有满足以下条件时才允许 K 调度：

- EKF 已锁定；
- 视觉数据在有效新鲜度内；
- 速度没有突然跳变；
- 速度方向与机体前向基本一致；
- 当前没有撞击或目标丢失异常。

否则保持上一组 K；严重异常时退回 `K6`。

### 6.3 最终速度来源

如果需要让调度真正对应气动舵效，最终应使用空速测量，例如皮托管/差压传感器。

在没有空速传感器的情况下，推荐把调度幅度限制在经过实测的窄范围内，不能盲目使用 2～20 m/s 的大范围调度。

## 7. 阶段五：分离速度调度和状态机

建立两个逻辑量：

```text
V_sched：只用于生成 K(V)
V_state：只作为状态机的辅助信息
```

不能让速度估计一次波动同时造成：

```text
速度异常 → K 改变 → 状态机结束 → 舵面回中
```

速度下降可以作为撞击后的辅助现象，但不应作为唯一结束条件。

建议结束判据组合：

```text
达到最短制导时间
+ 冲击加速度满足条件
+ 视觉/距离状态满足条件
+ 速度变化与撞击一致
```

如果只有速度下降，没有冲击和视觉证据，则继续保持 `Terminal`。

## 8. 阶段六：重新检查 MATLAB 模型

当前模型主要使用：

```text
B(V) ∝ V²
```

需要确认真实系统是否满足这一规律。重点检查：

- 使用的是空速还是地速；
- 舵面到力矩的真实比例；
- 舵机响应延迟；
- 气动阻尼；
- 迎角变化；
- 舵面限幅；
- 四片舵面的实际不一致；
- 尾端姿态变化造成的舵效变化。

仿真中应使用：

```text
B_true(V_actual) 与 K(V_measured)
```

而不是默认 `B_model(V)` 与 `K(V)` 始终完全匹配。

### 8.1 速度表替代五阶多项式

最终推荐：

```text
离散速度节点 + 分段线性插值
```

不建议继续使用大范围五阶多项式作为最终调度器，因为单个 K 元素拟合误差小，不代表闭环极点和舵面输出一定可靠。

## 9. 阶段七：积分与 LQI

积分测试顺序：

```text
固定 K6、无积分
→ 固定 K6、有积分，消除静态误差
→ 实时 K(V)、无积分，验证调度动态稳定性
→ 实时 K(V)、使用已有积分参数
→ 必要时设计 Ki(V)
```

当前积分项复用了 K 的角度列，因此 K 变化时，旧积分状态映射到舵面的控制量也会改变。

如果出现：

```text
实时 K + 无积分正常
实时 K + 有积分变差
```

则说明积分状态和 K(V) 发生了耦合。

最终严格的 LQI 形式应为：

```text
u = -Kx(V) × x - Ki(V) × z
```

而不是继续使用 `Kx(V)` 直接复用前三列来驱动积分项。

积分必须保留：

- 积分分离；
- 舵面饱和抗积分饱和；
- 目标丢失时冻结或清除；
- 状态切换时防止积分突变；
- K 切换时无扰处理。

## 10. MATLAB 仿真验证

至少建立四组仿真：

### A. 固定 K6、真实速度变化

验证固定 K 的鲁棒性。

### B. 理想速度调度

```text
V_measured = V_true
K = K(V_true)
```

验证理论调度本身是否有效。

### C. 带速度误差的调度

```text
V_measured = V_true + bias + noise + delay
K = K(V_measured)
```

验证速度可信度对闭环的影响。

### D. 设计模型与真实模型不一致

```text
B_true(V) != B_model(V)
```

这是解释“固定 K6 反而更好”的关键仿真。

所有仿真加入：

- 舵面限幅；
- 舵机延迟；
- 50 Hz K 更新；
- 速度跳变；
- 积分；
- 末端冲击；
- 状态机结束条件。

## 11. 硬件验证顺序

### 台架阶段

1. 固定 K6，验证三轴符号和角速度阻尼；
2. 固定速度输入，逐个速度点切换 K；
3. 观察每个速度点的舵面输出和角速度响应；
4. 验证 K 切换是否产生输出跳变；
5. 验证速度失效时是否回退 K6；
6. 验证状态机不会因速度短时波动提前结束。

### 飞行阶段

1. 固定 K6、无积分；
2. 固定 K6、有积分；
3. 小范围速度调度、无积分；
4. 小范围速度调度、有积分；
5. 扩大速度调度范围；
6. 最后再评估是否需要严格的 LQI(V)。

每次只改变一个变量，保留固定 K6 作为随时可回退的对照路径。

## 12. 判定分支

### 情况一：无积分时实时 K 已经变差

优先检查：

- 速度可信度；
- `B(V)` 模型；
- 空速/地速差异；
- K 更新连续性；
- 舵面饱和；
- 未建模气动阻尼。

### 情况二：无积分正常，有积分后变差

优先检查：

- 积分状态与 K(V) 的耦合；
- 积分抗饱和；
- 目标变化时积分是否保留；
- 状态切换时积分是否突变。

### 情况三：控制输出正常，但突然不控

优先检查：

- `Guidance_State` 是否提前进入 `End`；
- 速度是否被状态机误判；
- 撞击判据是否提前触发；
- 舵面输出是否被状态机清零。

### 情况四：速度升高后角速度逐渐增大

重点比较：

```text
u_gyro_fixed
u_gyro_schedule
```

并检查实时 K 是否假设气动舵效增加过快，导致实际闭环阻尼不足。

## 13. 最终推荐路线

```text
固定 K6 建立基线
→ 固定 K6 调好积分
→ 关闭积分隔离实时 K 问题
→ 记录 K_angle/K_gyro 实际控制贡献
→ 验证速度可信度
→ 分离 V_sched 与 V_state
→ 使用机体系前向速度作为临时代理
→ 增加有效性门控和无扰 K 切换
→ 用查表替代五阶多项式
→ 用真实 B(V) 重新计算 K
→ 恢复积分并检查耦合
→ 最后设计严格的增益调度 LQI
```

本计划只定义验证和开发顺序，具体增益、阈值、速度范围和切换时间以 MATLAB、台架和飞行数据为准。Keil 编译、下载和硬件效果均待实际验证。
